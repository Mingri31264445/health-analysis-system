# 初審意見統整與改進方向

## 老師主要在提醒什麼

兩位老師的意見可以整理成五個重點：

1. 目前題目方向有趣，但需要更清楚說明使用對象、現況需求與實際問題。
2. 如果要做臉部或皮膚狀態追蹤，不能只做單張照片辨識，還要思考不同時間照片如何比較。
3. 健康問卷、BFS、經絡儀資料不能只是並列功能，必須說清楚它們如何協同支持同一位受測者的健康追蹤。
4. 臉部影像屬於敏感資料，需要補上資料保護、權限控管與儲存策略。
5. 文件中的非功能規格與可行性分析太概念化，需要寫成可檢查的具體標準。

## 系統定位調整

本系統不應只定位為「單張臉部影像辨識工具」，而是：

「以受測者帳號為核心，整合健康問卷、面診影像、BFS 與經絡儀資料，提供長期健康資料管理與輔助觀察的整合平台。」

這樣可以回應老師提出的問題：系統不是每個檢測各做各的，而是讓同一位受測者的資料集中管理，方便後續追蹤、查詢與比較。

## 使用者與資料邏輯

正式系統應以「受測者帳號」作為資料主體：

- 一個受測者帳號只能有一份最新健康問卷。
- 一個受測者帳號可以有多筆面診影像紀錄。
- 一個受測者帳號可以有多筆 BFS 測試紀錄。
- 一個受測者帳號可以有多筆經絡儀測試紀錄。
- 後台人員搜尋到受測者後，可以查看該受測者四項資料狀態與歷史紀錄。

這能避免「新增一筆 BFS 就多出一個帳號」的錯誤，也比較符合長期追蹤情境。

## 健康問卷的意義

健康問卷不是拿來直接判斷皮膚病，而是作為背景資料與輔助分析依據。它的用途包括：

- 建立受測者基本資料，例如姓名、性別、生日、身高、體重。
- 記錄病史、過敏、生活習慣與睡眠運動狀況。
- 提供面診影像、BFS 與經絡儀資料判讀時的背景脈絡。
- 讓後續長期追蹤時，可以知道受測者狀態是否改變。

## 面診影像後續應補強

老師特別提到，若要長期追蹤臉部狀態，需要考慮拍照一致性與跨時間比較。因此後續功能應規劃：

- 拍攝引導：提示使用者保持正面、距離、光線與角度一致。
- 多角度紀錄：正面、左側、右側影像分開保存。
- 長期比較：同一受測者不同日期的照片要能放在一起比對。
- 位置追蹤：未來可用臉部特徵點作為參考，觀察同一位置的變化。
- 結果呈現：以趨勢圖或時間軸呈現異常區域變化。

## 隱私與資料保護

臉部影像屬於敏感生物特徵資料，因此文件與系統應補上：

- 所有個人資料與檢測資料必須登入後才能查看。
- 一般受測者只能查看自己的資料。
- 研究人員可以查看全部受測者資料，但不能管理帳號。
- 管理員可以管理帳號、群組與資料。
- 未來若加入 AI 影像分析，應優先考慮只保存必要分析結果，減少原始影像外流風險。
- 若需要保存原始影像，應限制檔案存取權限並避免公開路徑直接暴露。

## 非功能規格具體化

原本文件不能只寫「系統要方便、安全、穩定」，需要補成可檢查的標準。

### 易用性

- 使用者可在 1 分鐘內完成註冊與登入。
- 健康問卷依主題分段，降低一次填寫的負擔。
- 後台人員可用姓名、手機或 Email 搜尋受測者。
- 後台人員進入受測者作業台後，可在同一頁看到四項資料完成狀態。

### 安全性

- 所有檢測資料頁面皆需登入。
- 受測者只能存取自己的資料。
- 研究人員與管理員依群組或後台權限取得不同資料範圍。
- 密碼以 Django 內建雜湊機制保存，不儲存明文密碼。

### 可維護性

- 問卷、面診、BFS、經絡儀資料以不同模型管理。
- 檢測資料透過使用者外鍵綁定受測者帳號。
- 後續新增檢測模組時，可沿用同一套受測者歸屬與權限規則。

### 可用性

- 表單輸入需有基本驗證，避免明顯錯誤資料進入資料庫。
- 重要資料建立與更新後，系統需導回可確認結果的頁面。
- 後台列表需支援搜尋與篩選，避免資料量增加後難以查找。

## 可行性分析

目前系統可行性可從三個層面說明：

1. 技術可行性：Django 可處理使用者登入、資料模型、權限控管、檔案上傳與後台管理，符合目前專題需求。
2. 功能可行性：健康問卷、BFS、經絡儀與面診紀錄可分階段完成，不必一次完成完整 AI 模型。
3. 時程可行性：先完成受測者資料歸屬、後台搜尋、檢測紀錄管理與資料展示，再逐步補強影像分析與長期比較功能。

## 對應目前已改進項目

- 註冊流程已改為姓名、手機、Email 與密碼分開填寫。
- 手機號碼作為登入帳號，姓名只作為顯示與受測者辨識。
- 問卷、BFS、經絡儀、面診資料已加入使用者歸屬概念。
- 後台工作台已改為受測者導向，可查看單一受測者四項資料狀態。
- 後台已加入受測者搜尋與狀態篩選，資料多時可依缺問卷、缺面診、缺 BFS、缺經絡儀等狀態快速定位。
- 已新增受測者詳細頁，集中呈現基本資料、四項檢測狀態與歷史紀錄。
- 權限角色已整理為受測者、研究人員、管理員三種。
